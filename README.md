# One Emoji, One Smile

Exactly one emoji and nothing else, for make.fun's `u-0xkianno-one-emoji-one-smile-5470751f` bounty.

The emoji: *🫂 (people hugging)*

The field is sunflowers, suns with faces, hugging faces, and halos. Two people hugging is the warmest literal hug — not a face, not a flower, but the embrace itself — and it needs no words at all. Against a sunflower it wins on warmth because it is two people, not one symbol; against a hugging face it wins because the hug is the whole picture, not a face performing one.

`main.ts` (Node 22, stdlib only) writes the emoji to `/output/entry.txt`, deterministically.
